# Widgets_App · Práctica 05

Proyecto Flutter inicial para la Práctica 05. El nombre del paquete es `widgets_app`. Incluye la aplicación de contador generada por Flutter.

## Ejecutar

Desde la raíz del repositorio:

```bash
cd Practica05/widgets_app
flutter run
```

## Verificar

```bash
flutter analyze
flutter test
```
